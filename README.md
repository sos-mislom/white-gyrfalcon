# Белый кречет — тренажёр смены

Монорепозиторий первой фазы симулятора работы проводника ВСМ.

## Состав

- `apps/api` — NestJS API без URL-версионирования;
- `apps/web` — мобильный клиент на Next.js;
- `packages/api-contracts` — общие DTO и схемы проверки данных;
- `packages/simulation-core` — детерминированное ядро смены;
- `.private/contracts` — исходные документы заказчика, исключённые из Git.

## Запуск

```bash
npm install
npm run dev
```

API будет доступен на `http://localhost:3100`, Swagger — на
`http://localhost:3100/docs`, клиент — на `http://localhost:3000`.

## Принципы

- нормативные документы не попадают в репозиторий;
- DTO хранятся в коде и одинаковы для клиента и API;
- авторитетный скоринг остаётся детерминированным;
- генеративная модель подключается через адаптер и не меняет баллы напрямую;
- целевая архитектура — локальное исполнение и синхронизация; пока клиент вызывает API.

## Что уже работает

Первый кейс «Посадка без действительного билета»: проверка, объяснение, помощь, завершение;
ошибочные решения, эскалация, разбор и учебный скоринг. Сервер выбирает длительность действия,
проверяет DTO и защищает от повторного применения команды. OpenAPI строится из тех же Zod-схем.
Seed выбирает начальную реплику; это вариативность шаблона, ещё не генерация новых сценариев.

Баллы и таймеры — параметры прототипа, требуют калибровки экспертом. Safety/recovery пока не
оцениваются этим кейсом и не показываются в UI. Поля зарезервированы в общей модели.
Сессии хранятся в памяти, нет логина, офлайн-кэша, STT или локальной нейромодели.
Исходные документы датасета остаются в игнорируемой `.private/contracts`.
