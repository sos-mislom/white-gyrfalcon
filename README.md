# Белый кречет — тренажёр смены

Монорепозиторий симулятора работы проводника ВСМ. Текущая работа — серверный AI-цикл,
см. [контракт MVP](docs/CORE_MVP_SCOPE.md) и [фазу 3, шаг 1](docs/PHASE_3_STEP_1.md).

## Состав

- `apps/api` — NestJS API без URL-версионирования;
- `apps/web` — мобильный клиент на Next.js;
- `packages/api-contracts` — общие DTO и схемы проверки данных;
- `packages/simulation-core` — детерминированное ядро смены, replay и d20;
- `.private/contracts` — исходные документы заказчика, исключённые из Git.

## Запуск

```bash
npm install
npm run dev
```

API будет доступен на `http://localhost:3100`, Swagger — на
`http://localhost:3100/docs`, клиент — на `http://localhost:3000`.

## Принципы

- нормативные документы не попадают в репозиторий;
- DTO хранятся в коде и одинаковы для клиента и API;
- авторитетный скоринг остаётся детерминированным;
- генеративная модель подключается через адаптер и не меняет баллы напрямую;
- ходы исполняются локально, журнал синхронизируется и независимо пересчитывается сервером.

## Что уже работает

Первый кейс «Посадка без действительного билета»: проверка, объяснение, помощь, завершение;
ошибочные решения, эскалация, разбор и учебный скоринг. Сервер выбирает длительность действия,
проверяет DTO и защищает от повторного применения команды. OpenAPI строится из тех же Zod-схем.
Seed выбирает начальную реплику и бросок d20 при предложении помощи. Реакция пассажира меняет
его лояльность, но не профессиональную оценку. Это вариативность шаблона, ещё не генерация новых сценариев.

Баллы и таймеры — параметры прототипа, требуют калибровки экспертом. В новых попытках
boarding-3 допуск без билета снижает процедуру и безопасность; старые boarding-2
сохраняют прежний расчёт. Recovery пока не оценивается этим кейсом.
Клиент сохраняет журнал в IndexedDB и загружает production-оболочку без сети после первого открытия.
Production API хранит сессии в отдельной PostgreSQL; без PGHOST локальный dev использует память.
Нет логина, STT или локальной нейромодели. Данные сайта браузера нельзя очищать до синхронизации.
Исходные документы датасета остаются в игнорируемой `.private/contracts`.

На HomePage доступен свободный ввод. Настройте серверный AI_BASE_URL (origin llama.cpp,
без /v1) и необязательные AI_MODEL_NAME / AI_API_KEY. Без AI игра остаётся доступна через
явные кнопки. Модель возвращает действие и объяснение, движок — баллы и разрешённый исход.
AI-реплика хранится отдельно от детерминированного состояния.

HTTPS-стенд и порядок выпуска: [deploy/README.md](deploy/README.md).
